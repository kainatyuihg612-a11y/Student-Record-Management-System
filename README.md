# School Record Management System

A clean and dynamic console-based application built using *C++* and Object-Oriented Programming (OOP) concepts.

## 💡 Project Inspiration & Background
As an individual with practical part-time teaching experience, I closely observed how manual record-keeping takes up valuable teaching time. To solve this problem, I designed and coded this system during my *3rd Semester of Associate Degree Program (ADP) in Computer Science*. 

## 🚀 Features
- *Add New Student Data:* Efficiently add records including Name, Roll Number, Class, and Attendance.
- *View All Records:* Display the complete database of students with single-command transparency.
- *Search Functionality:* Instantly look up any student's data using their unique Roll Number.
- *Data Safety:* Built using secure C++ Vectors to manage memory efficiently.

## 🛠️ Concepts Used
- Object-Oriented Programming (OOP) - Classes and Objects
- Encapsulation (Private & Public Access Specifiers)
- Standard Template Library (STL) Vectors for Dynamic Storage
